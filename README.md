# Courtly

Prototype Flutter cho nền tảng đặt và quản lý sân cầu lông.

## Chức năng đã dựng

- Đăng nhập, đăng ký và tài khoản demo
- Trang chủ, tìm sân, yêu thích và hồ sơ
- Chọn sân, ngày, khung giờ và phương thức thanh toán
- Xác nhận đặt sân, xem lịch sử và hủy sân
- Dashboard quản trị với tổng quan doanh thu
- Quản lý lịch đặt/khung giờ, sân và tài khoản

## Chạy ứng dụng

```bash
flutter pub get
flutter run
```

Ứng dụng đang dùng dữ liệu mẫu trong bộ nhớ để trình diễn luồng giao diện. Các điểm tích hợp API đã được tách theo model và màn hình để thuận tiện nối backend ở giai đoạn sau.
